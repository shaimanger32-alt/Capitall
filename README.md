# Capitall

> **כל החיים הפיננסיים שלך, כגרף מניה אחד.**

אפליקציית אנדרואיד לניהול פיננסי אישי: נכסים, התחייבויות, עסקאות ותיק מניות — הכול במקום אחד, עם שווי נקי שמתעדכן בזמן אמת, ניתוח הרגלי הוצאה, יבוא אוטומטי של דפי חשבון מהבנק, ותיקים משותפים לניהול הוצאות עם בן/בת זוג או שותפים.

נכתב ב-Kotlin בארכיטקטורת MVVM, מעל Firebase ושלושה שירותי מידע פיננסי חיצוניים.

## מה האפליקציה עושה

### 📊 דשבורד
המסך הראשי מציג את **השווי הנקי** בגדול, עם כפתור עין להסתרה. מתחתיו:

- **גרף השווי הנקי** לאורך זמן, עם טווחי יום / שבוע / חודש / שנה / הכל
- **מצב השוואה בשתי אצבעות** — הנחת שתי אצבעות על הגרף מציגה שני קווי סמן, עם ערך ותאריך לכל אחד ותיבת הפרש ב-₪ ובאחוזים ביניהם (בסגנון TradingView)
- כרטיסי **KPI**: שווי נקי נזיל, הכנסה חודשית, הוצאה חודשית, שיעור חיסכון, תשלומים חוזרים
- **טיקר** מחירים חי בראש המסך
- גרף **תזרים מזומנים** ל-6 חודשים אחרונים, ופאי **הקצאת נכסים**
- **תובנות חכמות** — הקטגוריה היקרה ביותר החודש, אחוז החיסכון, התראה על חריגה
- עסקאות אחרונות, וחיפוש גלובלי

### 💼 נכסים והתחייבויות
הוספה של כל מה שיש לך וכל מה שאתה חייב, דרך **אקורדיון קטגוריות** צבעוני (מזומן, נדל״ן, השקעות, הלוואות ועוד). נכסים שאין להם מחיר שוק מקבלים **הערכת שווי אוטומטית** לפי שיעור שינוי שנתי ממוצע בקטגוריה שלהם.

### 📈 תיק מניות
- חיפוש מניות חי מול **Finnhub**, עם מחיר שוק מתעדכן
- מעקב רווח/הפסד לכל החזקה ולתיק כולו
- **גרף מניה** אינטראקטיבי בטווחים 1D / 1W / 1M / 6M / 1Y / 5Y / MAX
- מניות מנוהלות **בדולר** וכל השאר בשקל — ההמרה חיה, ולכן השווי הנקי מושפע גם מתנודות שער הדולר

### 👥 תיקים משותפים
פנקס הוצאות משותף לדירה, טיול או זוגיות:

- יצירת תיק מייצרת **קוד הזמנה בן 6 תווים** — להעתקה, שיתוף בוואטסאפ, או הקראה בטלפון
- כל שינוי מופיע אצל שאר החברים **מיד**, ללא רענון
- מסך **מאזן** שמחשב מי חייב למי, עם הצעת סילוק
- מה שאתה מנהל בתיק האישי נשאר פרטי — רק מה שנוסף בתוך התיק המשותף נראה לחברים

### 🔍 מסנן עסקאות (Screener)
טבלת כל העסקאות עם סינון משולב: טווח תאריכים, קטגוריות, הכנסה/הוצאה, וסכום מינימלי/מקסימלי — עם פס סטטיסטיקה שמתעדכן תוך כדי.

### 🔬 ניתוח עומק
בחירת קטגוריה מציגה: מגמת הוצאה חודשית מול קו תקציב, **דפוסי התנהגות** (למשל: "68% מההוצאה בקטגוריה הזו קורית מחמישי בערב עד שבת"), והתורמים המובילים. יש גם מצב מקביל לניתוח תיק המניות.

### 📥 יבוא דף חשבון
בחירת קובץ **PDF או CSV** שהורדת מאתר הבנק או חברת האשראי, והאפליקציה:

1. מזהה לבד את עמודות התאריך, התיאור והסכום (כולל עמודות חובה/זכות נפרדות)
2. משייכת קטגוריה לכל עסקה — **לומדת מההיסטוריה שלך**, כך שככל שתשתמש יותר הזיהוי משתפר
3. מסמנת עסקאות שכבר יובאו בעבר, כך שיבוא כפול בטוח
4. מציגה תצוגה מקדימה שבה אפשר לתקן קטגוריה או לבטל שורות לפני השמירה

### ⚙️ הגדרות
החלפת שפה (עברית / אנגלית, כולל RTL מלא), מטבע תצוגה (₪ / $ / €), הסתרת יתרות, ויבוא קבצים.

### 🔁 עסקאות חוזרות
עסקה שמסומנת כחוזרת נוצרת אוטומטית מדי חודש, על ידי משימת רקע יומית (WorkManager).

## ארכיטקטורה

**MVVM** עם זרימת נתונים חד-כיוונית:

```
Activity  ──observe──▶  ViewModel  ──▶  Repository  ──▶  Firestore
                                                     └─▶  Retrofit (REST)
```

- **`ui/`** — Activities ו-ViewModels. ה-Activity אחראי רק לתצוגה ולאירועי משתמש; אין בו לוגיקה עסקית.
- **`data/repository/`** — מקור האמת היחיד לנתונים. Firestore נחשף כ-`Flow` דרך `callbackFlow` שעוטף `addSnapshotListener`, כך שכל שינוי בשרת מגיע למסך בזמן אמת.
- **`data/remote/`** — ממשקי Retrofit ומודלים לשלושת ה-APIs החיצוניים.
- **`util/`** — **כל הלוגיקה הכבדה, ללא שום תלות ב-Android** — ולכן ניתנת לבדיקת יחידה רגילה: פענוח דפי בנק, שיוך קטגוריות, זיהוי כפילויות, חישוב מאזן בתיק משותף, המרות מטבע, ייצור עסקאות חוזרות, יישור סדרות זמן.
- **`di/ServiceLocator.kt`** — הזרקת תלויות ידנית. מספק singleton לכל repository (חוסך יצירה חוזרת, ומאפשר מטמון מחירים אחד). ה-ViewModels מקבלים את ה-repository כפרמטר עם ברירת מחדל מכאן, כדי שאפשר יהיה להחליף במופע מזויף בבדיקות.
- **`util/UiState.kt`** — מצב אחיד לכל מסך מבוסס-נתונים: `Loading` / `Success` / `Empty` / `Error`. מבחין בין "אין נתונים" לבין "טעינה נכשלה", במקום לבלוע שגיאה לרשימה ריקה.

## איך מריצים

### דרישות
- Android Studio (Hedgehog ומעלה)
- **JDK 17** (ה-JBR המצורף ל-Android Studio מתאים)
- מכשיר או אמולטור עם **Android 8.0 (API 26)** ומעלה

### שלבים

1. שכפול הפרויקט:
   ```bash
   git clone <repo-url> && cd Capitall
   ```

2. **הוספת מפתח Finnhub.** המפתח אינו נשמר ב-Git. הירשם בחינם ב-<https://finnhub.io/register>, והוסף ל-`local.properties`:
   ```properties
   FINNHUB_API_KEY=your_key_here
   ```
   > בלי המפתח האפליקציה תעלה ותעבוד, אבל **חיפוש המניות יחזיר תוצאות ריקות**.

3. בנייה והתקנה:
   ```bash
   export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
   ./gradlew :app:installDebug
   ```

4. *(אופציונלי — רק אם אתה מחבר פרויקט Firebase משלך)* פריסת חוקי האבטחה:
   ```bash
   firebase deploy --only firestore:rules
   ```
   בלי זה, יצירת תיק משותף תיכשל. האפליקציה מזהה את המקרה ומציגה הודעה מפורשת ולא שגיאה גנרית.

## החלטות תכנון מעניינות

**מזהה מסמך = קוד ההזמנה.** בתיק משותף, מזהה המסמך ב-Firestore *הוא* קוד ההצטרפות. כך ההצטרפות היא קריאה של מסמך יחיד ולא שאילתה — מה שמאפשר חוק אבטחה פשוט ובטוח: `get` מותר לכל משתמש מאומת (צריך לדעת את הקוד המדויק), אבל `list` מוגבל לתיקים שאתה כבר חבר בהם. אי אפשר לסרוק תיקים של אחרים.

**מטבע כפול, מקור המרה אחד.** מניות אמריקאיות מנוהלות בדולר; כל השאר בשקל. כל נקודה שבה שני העולמות נפגשים עוברת דרך `CurrencyConverter` יחיד עם שער במטמון, שמתעדכן בכל משיכת מחירים. התוצאה: השווי הנקי משקף גם תנודות בשער הדולר, כמו במציאות.

**מטמון עם TTL למחירים.** `MarketCache` בתוך `StockRepository` שומר מחירים ושערים ל-60 שניות והיסטוריה ל-5 דקות — כדי לא לחרוג ממכסת ה-API החינמית של Finnhub.

**PDF בלי טבלה.** לדפי חשבון של בנקים ישראליים אין מבנה טבלה ב-PDF, אלא טקסט מפוזר. הפתרון: חילוץ הטקסט **יחד עם קואורדינטות ה-X/Y** של כל מילה, ושחזור העמודות לפי מיקום אופקי.

**מצב השוואה בשתי אצבעות.** `ComparisonLineChart` היא הרחבה מותאמת אישית של MPAndroidChart: זיהוי שתי נגיעות מציג שני קווי סמן נצמדים לנקודות, תיבות ערך/תאריך מעל כל אחד, תיבת הפרש ביניהם, ועמעום של האזור שמחוץ לטווח. הרמת אצבע מחזירה את הגרף למצב רגיל.

## מגבלות ידועות

- **אין העלאת תמונות.** לא מומש Firebase Storage; במקומו יש שלושה שירותי REST חיצוניים וחוקי אבטחה בשרת.
- **מצב כהה הוסר בכוונה** לטובת שפת עיצוב בהירה אחידה (`ThemeManager` כופה `MODE_NIGHT_NO`).
- **ללא אינטרנט** — מחירי מניות ושערי חליפין לא ייטענו והמסך יציג הודעת שגיאה. האפליקציה לא קורסת, ו-Firestore ממשיך להגיש נתונים מהמטמון המקומי שלו.
- **PDF מוגן בסיסמה** (בנקים בישראל נוהגים להצפין לפי ת״ז) אינו נתמך; המקרה מזוהה ומוצגת הודעה שמסבירה מה לעשות.
- **בבניית Release** מופעל R8 — כל מודל חדש תחת `data/model/` או `data/remote/` חייב כלל `-keep` ב-`proguard-rules.pro`, אחרת ה-deserialization נשבר בזמן ריצה ולא בזמן בנייה.
